## 👋 About Me

I'm a backend-focused software engineer who enjoys the hard parts of distributed systems: keeping data consistent across services, surviving failures gracefully, and making everything observable. My main stack is **Java & Spring Boot**, and I also build **applied AI systems** with Python, PyTorch, and LangGraph.

- 🏗️ Designing **event-driven microservices** with Kafka, Saga, and Transactional Outbox
- 🧠 Building **agentic AI & RAG pipelines** that are explainable and verifiable
- 🧪 Writing tests that actually catch bugs: Testcontainers, Embedded Kafka, JUnit 5
- 🎓 Computer Engineering @ Burdur Mehmet Akif Ersoy University (graduating June 2027)

## 🧩 Patterns I Work With

| Problem | Pattern |
| :-- | :-- |
| Distributed transactions | Orchestrated Saga · Compensating actions |
| Dual-write & lost events | Transactional Outbox |
| Duplicate messages / requests | Idempotent consumers · Idempotency-Key |
| Race conditions | Optimistic locking (`@Version`) |
| Cascading failures | Circuit Breaker · Retry · Dead Letter Topics |
| Traceability | OpenTelemetry · Correlation IDs |
